# UI v1.4.3

## รูปแบบ

- โทนขาว เทา และน้ำเงิน ใช้เส้นแบ่งและกรอบบาง ปุ่มสี่เหลี่ยมมุมโค้งเล็ก
- เมนูด้านบนและชื่อระบบแบบข้อความ ไม่มีโลโก้ตกแต่งหรือรูปผู้ใช้สมมติ
- หน้าภาพรวมมีปุ่มเตรียมเรซูเม่ ตารางประวัติ 5 รายการล่าสุดจากข้อมูลจริง และวิธีใช้งานสั้น ๆ
- ใช้กล่องคำถามสัมภาษณ์ธรรมดา แทนวงกลม/ลูกแก้ว
- ไม่มี gradient, animation หรือข้อความเชิงโฆษณาบนหน้าหลัก
- คงเมนูพับสำหรับการตั้งค่าเสียง การจัดการเอกสาร และเครื่องมือประเมินโครงงาน
- ปรับการจัดวางบนหน้าจอแคบ ตารางประวัติเลื่อนแนวนอนได้

## การตรวจ

Frontend regression tests 7 กรณีผ่าน, production build ผ่าน และ HTTP smoke ผ่านหน้าเริ่มต้น/Next-FastAPI พร้อม workflow เดิม (ใช้ Ollama stub)
ไม่มีการเปลี่ยน backend/model pipeline ไม่ได้ทดสอบไมค์หรือคลิกหน้าเว็บด้วย browser จริงในรอบนี้
