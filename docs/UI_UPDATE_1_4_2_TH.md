# UI v1.4.2

## การเปลี่ยนแปลง

- หน้าหลักเน้น 3 ขั้น: เตรียมเรซูเม่ ซ้อมสัมภาษณ์ ดูคำแนะนำ
- เปลี่ยนศัพท์ในเมนูและปุ่มเป็นภาษาไทย และเว้นช่องไฟให้สแกนอ่านง่าย
- เริ่มฟอร์มด้วยข้อมูลว่าง ใช้ตัวอย่างสมมติได้เมื่อกดปุ่ม
- พับข้อมูลบริษัทเพิ่มเติม ที่มารายละเอียดงาน และการตรวจข้อความเรซูเม่
- มีทางไปซ้อมสัมภาษณ์หลังบันทึกข้อมูล แม้ยังไม่ได้ติดตั้งโมเดลวิเคราะห์ทักษะ (โหมด AI interview ยังต้องมี Qwen3)
- สรุปผลทักษะเป็นจำนวน “พบหลักฐาน / ยังไม่พบหลักฐาน” ตัวเลข similarity และ MiniLM อยู่ในรายละเอียด
- ห้องสัมภาษณ์เน้นคำถามและช่องคำตอบ พับการตั้งค่าเสียงและรายละเอียด latency
- แสดงรายงานก่อนประวัติ พับ CER/WER, F1 และการส่งออกหลักฐานไว้ในเครื่องมือโครงงาน
- พับการนำเข้า/จัดการคลัง FAQ ไว้ใต้หน้าถามตอบ
- ปรับขนาดและการจัดวางสำหรับหน้าจอแคบ โดยไม่เพิ่ม dependencies หรือเปลี่ยน API/model pipeline

## ผลตรวจ

- Frontend regression tests 7 กรณีผ่าน และ Next production build ผ่าน
- HTTP smoke ผ่าน Next -> FastAPI -> controlled Ollama stub: หน้าเริ่มต้นภาษาไทยและแผงตั้งค่าที่พับไว้, upload, session, profile, baseline/proposed interview, report, export และ delete
- ไม่ได้ทดสอบคลิกใน browser จริงหรือทดสอบไมค์ใหม่ การตรวจ HTML ที่ server render และ HTTP ไม่ได้ทดแทน browser interaction tests
- Backend/model pipeline ไม่เปลี่ยนจาก v1.4.1 ข้อจำกัดด้านโมเดลจริงและฮาร์ดแวร์ยังอ้างอิง TEST_REPORT_TH.md
